# 原生实现与验证记录

核对日期：2026-09-21。三个独立表盘已完成原生实现与本次模拟器验收，并按用户确认排除三款 8 色机型、保持其余 MIP 的原型配色。尚未进行实体手表测试或商店发布。

## 已完成实现

- `hour-white`、`hour-black`、`hour-color` 三个独立应用 ID、清单、图标与构建入口。
- 共用本地时间、时辰刻数、日期、电量、步数、有效心率与省电状态逻辑。
- 按原型生成 Noto Serif SC / Noto Sans SC 字形，覆盖 218、240、260、280、360、390、416、454、466 九种尺寸。
- 原型普通显示与省电显示；设备要求烧屏保护时省电全黑、恢复高功耗后显示完整表盘。
- 开发环境准备、设备状态核对、资源生成、PRG 构建、原生测试、固定数据场景、商店导出及包内容核验脚本。
- 字体原始版权声明、OFL 授权文件，以及嵌入应用的 `FontLicense` 资源。开发签名私钥仅存于 `.tools/signing/`。

## 构建结果

环境：macOS Apple Silicon、Java 17.0.20.1、Connect IQ SDK 9.2.0、官方 SDK Manager 设备资料。

| 检查 | 实际结果 | 证据 |
|---|---|---|
| 三主题 × 九种尺寸的正式 PRG | 27/27 通过，零警告、零错误 | `build/release/report.json` |
| 三个独立 IQ 导出 | 每款含 120 个设备目标、205 个地区硬件变体，零警告、零错误 | `build/export/report.json` |
| IQ 包内覆盖检查 | 三款的应用 ID、设备 PRG、205 个地区硬件变体均吻合；无预览与测试入口，含字体授权资源 | `build/export/verification.json` |
| 资源检查 | 4/4 通过 | `python3 -m unittest discover -s tests -p 'test_*.py'` |

导出包通过官方编译器实际生成，不是更改扩展名或拼接的文件。`verify_exports.py` 解读 `.iq` 中的官方清单，并对照本机设备资料核对每个地区硬件变体。记录 SHA256 用于后续交付核对。

官方兼容表原清单包含 124 个圆屏目标；按用户确认排除 Forerunner 45、Forerunner 55、Garmin Swim 2 后，目标范围为 121 个，本次可构建 120 个。尚未取得 **Venu Mercedes-Benz Collection** 的独立设备包，SDK Manager 的 API 3.3 列表中未见该条目，因此没有将其计入本次构建覆盖。

## 原生自动测试

当前支持范围内四款代表设备分别运行六项测试，共 **24/24 通过**：fēnix 3、fēnix 3 HR、Venu、fēnix 9 Pro 51mm。早期 Forerunner 45 的六项探索测试也通过，但该机型已按用户决定排除，不计入支持范围。

每款的完整原生日志与汇总位于 `build/tests/hour-white/<设备>.simulation.log`、`<设备>.test-result.json`。

1. 从 23:00 开始逐分钟检查完整 1,440 分钟的时辰及刻数。
2. 检查 22:59、23:00、23:14/15、23:44/45、23:59、00:00、00:59、01:00 边界。
3. 检查 12/24 小时制、午夜 12 点、上午/下午、日期与星期格式。
4. 检查 null、0、255 等无效心率，五分钟有效期边界、未来样本、缺失步数、电量上下界。
5. 检查有/无烧屏保护设备的省电与唤醒判定。
6. 调用实际设备 API 读取一次正常数据与省电数据，核对取值范围；Venu 和 fēnix 9 Pro 返回烧屏保护标志，fēnix 3 和 fēnix 3 HR 返回 false。

测试运行在官方模拟器，健康数据为模拟器提供的数据；尚未进行实体手表佩戴测试或电池续航测量。

## 已确认的视觉边界

1. **8 色机型**：用户确认不支持 Forerunner 45、55、Garmin Swim 2，三个应用的目标生成器和清单均已排除。
2. **白款 16/64 色 MIP**：用户确认严格映射原型配色，接受普通分区与背景合并。浅灰 `#E2E1E4` 和浅底 `#F8F3E6` 会映射到同一白色；当前时辰的强调色与向内突出仍保留。

原型已同步为 218–466 像素及上述兼容说明，其余布局与原色保持一致。当前导出包用于后续实表测试和商店准备；本次没有上传商店。
